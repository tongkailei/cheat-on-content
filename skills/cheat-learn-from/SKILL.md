# Cheat-Learn-From：对标账号导入

分析对标账号的视频 pattern，为 rubric 提供校准信号。

---

## 前置检查

1. **确认 .cheat-state.json 存在**
2. 确认 `benchmark.md` 存在，如不存在则创建

---

## Step 1：获取账号信息

用户说"学 <账号名>"或"找对标"，询问：

```
🎯 导入对标账号

请提供：
1. 账号名/ID：<平台 @账号名>
2. 平台：抖音 / B站 / 视频号 / YouTube / 小红书 / 其他
3. 视频数量：要分析几条？（建议 5-10 条）
```

---

## Step 2：搜索账号

用 `web_search` 搜索账号信息：

```
搜索："<平台> <账号名> 主页"
搜索："site:<平台>.com <账号名>"
```

找到账号主页 URL 和基本信息。

---

## Step 3：抓取视频列表

用 `web_fetch` 抓取账号主页，列出最近视频。

---

## Step 4：选择视频分析

列出抓取到的视频，让用户选择要分析的条数：

```
📊 检测到 <n> 条视频

选择要分析的条数（建议 5-10 条）：
1. 最近 5 条
2. 最近 10 条
3. 指定条数：<n>
```

---

## Step 5：逐条分析

对每条视频分析：

| 维度 | 评估 | 证据 |
|---|---|---|
| 标题 | 好/坏/一般 | 为什么 |
| 封面 | 好/坏/一般 | 为什么 |
| 话题 | 什么类型 | 热度如何 |
| 结构 | 如何展开 | 开头/高潮/收尾 |
| 时长 | 几分几秒 | 平台规律 |
| 数据 | 播放量大概在什么量级 | 估算 |

---

## Step 6：生成 Pattern 报告

```markdown
# 对标账号分析报告

## 账号信息
- 平台：<平台>
- 账号名：<账号名>
- 分析视频数：<n> 条

## 共同 Pattern

### 话题选择
- 主要类型：<类型1、类型2、...>
- 话题来源：<热点追踪/原创观点/知识输出/...>
- 时效性：<追热点/长期有效>

### 标题规律
- 常用句式：<列出常见模式>
- 字数范围：<x-y 字>
- 特点：<情绪化/疑问句/数字/...>

### 封面规律
- 风格：<真人出镜/图文/文字为主/...>
- 常用元素：<列出>
- 颜色：<冷色调/暖色调/高对比/...>

### 结构规律
- 平均时长：<x 分钟>
- 开头方式：<如何抓注意力>
- 高潮位置：<开头/中间/后期>
- 结尾方式：<总结/悬念/互动/...>

### 数据估算
- 播放量估算：<量级>
- 互动率估算：<点赞/播放 比>

## 可借鉴点
1. <点1>
2. <点2>
3. <点3>

## 需避免的点
1. <点1>
2. <点2>
```

---

## Step 7：更新 benchmark.md

追加到 `benchmark.md`：

```markdown
## <账号名>

- 平台：<平台>
- 分析时间：<YYYY-MM-DD>
- 分析视频数：<n> 条
- 参考页：<samples/账号名/>

### 核心 Pattern
<简要列出 3-5 条>
```

---

## Step 8：存入 samples 目录

```
samples/
└── <账号名>/
    └── meta.md    # 存放账号基本信息
```

---

## Step 9：派生 rubric 信号

从分析中提取可以加入 rubric 的观察：

```
💡 派生信号

从对标账号中学到的：

1. 话题维度：<具体观察>
   → 可以加入 rubric_notes.md 的观察笔记

2. 结构维度：<具体观察>
   → 可以加入 rubric_notes.md 的观察笔记

...
```

---

## 注意事项

- 分析视频数量越多，pattern 越准确，但分析时间也越长
- 对标账号最好选近期数据稳定的（避免选正在上升或下降的账号）
- 可以导入多个对标账号，cross-reference 找共同 pattern
