# Cheat-Recommend：候选池排序推荐

从 candidates.md 中按策略推荐选题。

---

## 前置检查

1. **确认 .cheat-state.json 存在**
2. **确认 candidates.md 存在且非空**
3. 读取 buffer 状态

---

## 推荐策略

根据 buffer 状态决定推荐策略：

| Buffer 数量 | 策略 | 说明 |
|---|---|---|
| 0 | 1 稳 + 1 实验 | 先保底，再探索 |
| 1 | 1 稳 | 继续积累信心 |
| 2 | 1 实验 | 探索新方向 |
| ≥3 | 暂不推荐 | 建议先消化 |

---

## Step 1：读取候选池

读取 `candidates.md`，筛选状态为"pending"的选题。

---

## Step 2：排序

按以下因素排序：

1. **稳定性分数**：基于历史复盘数据，预测更稳的选题
2. **时效性**：热点话题优先
3. **差异化**：避免和最近已拍内容重复

---

## Step 3：输出推荐

```
🎯 选题推荐

Buffer 状态：<n> 个待发布
推荐策略：<策略名称>

┌─────────────────────────────────────────────────────────┐
│ ✅ 推荐 1（稳）                                         │
│ 标题：<选题标题>                                        │
│ 来源：<热点/对标/自选>                                  │
│ 理由：<2-3句话>                                        │
│ 预计难度：🟢 简单                                       │
├─────────────────────────────────────────────────────────┤
│ 🔬 推荐 2（实验）                                       │
│ 标题：<选题标题>                                        │
│ 来源：<热点/对标/自选>                                  │
│ 理由：<2-3句话>                                        │
│ 预计难度：🟡 中等                                       │
│ 风险：<如果有>                                         │
└─────────────────────────────────────────────────────────┘

💡 说明：
- 稳 = 有把握，预计表现稳健
- 实验 = 探索性，可能爆也可能扑
```

---

## Step 4：用户选择

```
选择一个开始：

1. "拍 #1" 或 "拍稳的" → 开始做 <稳选题>
2. "拍 #2" 或 "拍实验的" → 开始做 <实验选题>
3. "两个都拍" → 建议先拍稳的，再拍实验的
4. "都不满意" → "抓热点"找新的
```

---

## Step 5：更新状态

用户选择后，更新 `candidates.md` 中选题的状态：

```markdown
| # | 选题 | 来源 | 添加时间 | 状态 |
|---|---|---|---|---|
| 3 | <标题> | <平台> | <时间> | in-progress |
```

---

## 输出

```
📝 选题已选定：<标题>

下一步：
1. "打分这篇" → 评估草稿质量
2. "启动预测" → 写盲预测
3. 直接写草稿 → 写完后"打分这篇"
```

---

## 注意事项

- 推荐数量固定为 2 个（1稳+1实验），避免选择困难
- 如果候选池不足 2 个，列出所有可用选题
- 状态为"in-progress"的选题不重复推荐
