# Cheat-Seed：冷启动选题

从 0 开始，帮用户找到前 5 个可拍的选题。只在 cold-start 阶段用一次。

---

## 前置检查

1. **确认 .cheat-state.json 存在**
2. **确认 mode = cold-start**（calibration 用户走 candidates.md）
3. **如果校准池已有样本**，建议走"推荐选题"

---

## Step 1：了解用户

询问用户基本信息：

```
🌱 冷启动选题

在开始之前，帮我了解你：

1. 你做哪个平台？（抖音/B站/视频号/小红书/YouTube/其他）
2. 你的账号定位是什么？（知识科普/评论吐槽/生活方式/...）
3. 你擅长什么领域？（科技/财经/职场/情感/美食/...）
4. 你现在有多少粉丝？（0起步/已有少量/已有一定基础）
5. 每周能拍几条？（1条/2-3条/日更/...）
```

---

## Step 2：分析热点和趋势

用 `web_search` 和 `web_fetch` 抓取：

1. **平台热点**：搜索"平台名 + 近期热点/爆款话题"
2. **领域热点**：搜索用户擅长领域 + 当前趋势
3. **对标账号**：如果有 benchmark.md，分析对标账号近期在拍什么

---

## Step 3：生成选题候选

基于分析，生成 5 个选题候选：

格式：

```
🌱 冷启动选题推荐

基于你的定位：<定位>
擅长领域：<领域>
平台：<平台>

推荐前 5 个选题：

┌─────────────────────────────────────────────────────────┐
│ #1 <选题标题>                                          │
│ 类型：<热点追踪/观点表达/知识科普/...>                   │
│ 预期难度：🟢 简单 / 🟡 中等 / 🔴 难                     │
│ 为什么值得拍：<2-3句话理由>                            │
│ 潜在风险：<如果有问题的话>                              │
├─────────────────────────────────────────────────────────┤
│ #2 <选题标题>                                          │
│ ...                                                     │
└─────────────────────────────────────────────────────────┘
```

---

## Step 4：让用户选择

```
请选择你想拍的选题：

1. "<选题1标题>" → 说"拍这个"
2. "<选题2标题>" → 说"拍这个"
3. "<选题3标题>" → 说"拍这个"
4. "<选题4标题>" → 说"拍这个"
5. "<选题5标题>" → 说"拍这个"
6. 都不满意 → 说"再生成5个"
```

---

## Step 5：创建草稿

用户选择后，帮助用户创建第一个草稿：

```
📝 创建草稿

选题：<选题标题>

帮你创建一个草稿框架，你可以继续修改：

# <标题>

## 核心观点
<1-2句话概括>

## 开头（钩子）
<如何开场，抓住注意力>

## 正文
<主要论点/论述>

## 结尾
<如何收尾>
```

保存到 `scripts/YYYY-MM-DD_seed_<short-title>.md`

---

## 后续

- 草稿创建后 → "打分这篇" 或 "启动预测"
- 继续选更多选题 → 添加到 `candidates.md`

---

## 注意事项

- cold-start 用户只需要做一次 seed，之后走正常流程
- 选题要有差异化，避免重复对标账号的内容
- 优先选有把握的选题，cold-start 阶段建立信心很重要
