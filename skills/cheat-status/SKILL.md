# Cheat-Status：状态看板

读取 .cheat-state.json 和 STATUS.md，输出当前项目状态。

---

## 读取数据

1. 读取 `.cheat-state.json`
2. 读取 `STATUS.md`
3. 扫描 `predictions/` 目录统计状态
4. 扫描 `candidates.md` 统计候选池

---

## Buffer 警戒规则

| Buffer 数量 | 状态 | 建议 |
|---|---|---|
| 0 | 🟢 正常 | 正常流程 |
| 1-3 | 🟡 警戒 | 尽快发布或取消 |
| > 3 | 🔴 危险 | 建议先消化再拍新内容 |

---

## 特殊状态

### Cold-Start 模式
```
⚙️  模式：cold-start
📝 说明：< 5 个校准样本，预测简化版
💡 建议：积累 5 个复盘数据后"升级 rubric"解锁完整预测
```

### Calibration 模式
```
⚙️  模式：calibration
📝 说明：≥ 5 个校准样本，完整预测已解锁
💡 建议：持续复盘迭代 rubric 精度
```

---

## 注意事项

- 如果 .cheat-state.json 不存在，告知用户需要"初始化"
- 如果 predictions/ 目录为空，相应区域显示"暂无"
- 待复盘按发布时间排序，最早的排在前面
