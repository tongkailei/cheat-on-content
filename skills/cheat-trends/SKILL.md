# Cheat-Trends：热点抓取

搜索当前热点，给候选池补充选题。

---

## 前置检查

1. **确认 .cheat-state.json 存在**
2. 读取 `projectDir` 确认项目目录

---

## Step 1：确定搜索范围

询问用户：

```
🔥 抓热点

搜索范围：
1. 全平台热点（抖音+B站+微博+小红书）
2. 指定平台：<用户选择>
3. 指定领域：<用户选择>

或者直接说"抓热点"我按默认来
```

默认：搜索用户擅长领域 + 全平台热点。

---

## Step 2：搜索热点

用 `web_search` 搜索：

```
# 搜索策略

1. "<平台> 近期热点 2025"
2. "<领域> 热门话题"
3. "最近什么视频火"
4. "热搜 今日"
```

抓取搜索结果，提炼热点话题。

---

## Step 3：过滤和排序

过滤掉：
- 时效性已过的（> 1周）
- 明显超出能力范围的
- 和已有选题重复的

排序优先级：
1. 和用户定位匹配度高
2. 时效性强（越新鲜越好）
3. 有差异化角度

---

## Step 4：输出热点报告

```
🔥 热点速报

搜索时间：<YYYY-MM-DD HH:mm>
平台：<范围>
领域：<领域>

┌─────────────────────────────────────────────────────────┐
│ 🔥 HOT <热点标题>                                      │
│ 来源：<平台>                                           │
│ 热度：🔥🔥🔥 高 / 🔥🔥 中 / 🔥 低                      │
│ 时效性：<2小时内/今日/本周>                             │
│ 适合角度：<2-3个切入角度>                               │
│ 风险：<如果有问题>                                      │
├─────────────────────────────────────────────────────────┤
│ 💡 <热点标题>                                          │
│ ...                                                     │
└─────────────────────────────────────────────────────────┘
```

---

## Step 5：添加到候选池

询问用户是否要把热点加入候选池：

```
是否加入候选池？

1. "全部加入" → 加入 candidates.md
2. "加入 #1, #3" → 只加入指定的
3. "暂不加入" → 只看不加
```

如果用户选择加入，更新 `candidates.md`：

```markdown
## 候选选题

### <日期> 热点补充

| # | 选题 | 来源 | 添加时间 | 状态 |
|---|---|---|---|---|
| 1 | <标题> | <平台> | <时间> | pending |
...
```

---

## Step 6：后续

加入候选池后：
- "推荐选题" → 从候选池推荐（按 buffer 状态）
- "打分这篇" → 对某个热点写草稿
- "启动预测" → 直接对热点选题做预测

---

## 注意事项

- 热点有窗口期，越早拍越好
- 避免追已经烂大街的话题，要找差异化角度
- 可以用 `web_fetch` 深入看某个热点详情
